# Prompts for Codex

Copy the prompt that matches the current phase, replace its placeholders, and name the relevant files or task record. These prompts are reusable starting points, not commands that run automatically.

| Goal | Prompt |
| --- | --- |
| Investigate a substantial request and write a plan | [Plan](plan.md) |
| Implement a focused change or an authorized plan | [Implement](implement.md) |
| Continue work already in progress | [Resume](resume.md) |

Use no task record for a small, contained fix. Use `.codex/workflow/templates/task.md` for substantial work so decisions, scope and verification stay together. Pick a matching skill from `AGENTS.md`; do not load every skill for every task.
