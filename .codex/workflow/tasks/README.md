# Task records

[Workflow guide](../README.md) · [Task template](../templates/task.md)

Keep one descriptive Markdown file per substantial task, for example
`benchmark-checkpoint-recovery.md`. Copy the template and replace its placeholders.
Track the plan, decisions, verification and next action together in that file.
Update it when the work materially changes, not after every tool call.

Keep completed records for handoff; do not overwrite a previous task to begin a
new one. Requirements here do not override the user's latest instructions or
implicitly authorize experiment runs, data deletion or paid API calls.
