
\chapter{Experiments}\label{chap:experiments}

This chapter details the empirical methodology, experimental configurations, mathematical metric formulations, and multi-stage evaluation pipeline designed to answer the core research questions of this thesis. The primary objective is to investigate whether localized Large Language Models (LLMs) can autonomously synthesize competitive, noise-resilient continuous optimization heuristics, how prompt scaffolding and model parameter scaling govern algorithmic discovery, and whether synthesized search logic generalizes across extended evaluation horizons and continuous dimensions.

%-------------------------------------------------------------------------------
\section{Empirical Research Questions}\label{sec:exp_rqs}

The experimental evaluation framework operationalizes the inquiry into three Primary Research Questions ($\mathbf{RQ1}$--$\mathbf{RQ3}$) and three Operational Sub-Questions ($\mathbf{Sub}\text{-}\mathbf{RQ\ A}$--$\mathbf{Sub}\text{-}\mathbf{RQ\ C}$):

\begin{itemize}
    \item \textbf{RQ1 (Autonomous Synthesis and Competitiveness):} Can localized LLMs autonomously synthesize continuous optimization heuristics that match or outperform established classical baselines---specifically Covariance Matrix Adaptation Evolution Strategy (CMA-ES) \cite{Hansen2001}, Differential Evolution (DE) \cite{Storn1997}, and Particle Swarm Optimization (PSO) \cite{Kennedy1995}---across standard continuous benchmark landscapes under deterministic conditions?
    
    \item \textbf{RQ2 (Noise Resilience in Autonomous Design):} Can localized LLMs autonomously synthesize continuous optimization heuristics that are structurally resilient to stochastic evaluation noise ($\sigma = 0.05$)?
    
    \item \textbf{RQ3 (Cross-Environment Robustness and Transfer):} How does the cross-environment retention and performance degradation of noise-evolved heuristics compare against heuristics synthesized under clean, deterministic baselines?
    
    \item \textbf{Sub-RQ A (Model Parameter Capacity Scaling):} How does the underlying LLM parameter capacity ($3\text{B}$, $7\text{B}$, and $14\text{B}$ parameters within the \texttt{Qwen2.5-Coder} family) govern the mathematical sophistication, algorithmic novelty, and search efficiency of synthesized code?
    
    \item \textbf{Sub-RQ B (Prompt Scaffolding Ablation):} How does the semantic and structural design of prompt scaffolding (\textsc{Baseline}, \textsc{Guided}, \textsc{Thinking}, and \textsc{Vectorization}) influence evolutionary trajectories relative to unguided control prompts?
    
    \item \textbf{Sub-RQ C (Synthesis-to-Evaluation Horizon and Dimensionality Scaling):} Do candidate heuristics synthesized under low evaluation budgets ($B_{\text{synth}} = 1{,}000$ function calls) generalize when deployed across full-scale long-horizon benchmarking budgets ($B_{\text{eval}}(D) = 10{,}000 \times D$, up to $100{,}000$ function calls in $10\text{D}$)?
\end{itemize}

\section{In-Depth Algorithmic Synthesis and Prompt Scaffolding Mechanics}\label{sec:exp_synthesis_mechanics}

The automated generation of search heuristics operates via the Large Language Model Evolutionary Algorithm (LLaMEA) paradigm \cite{LLaMEA2024}. Rather than relying on rigid, pre-programmed numerical crossover routines, the LLM functions as a high-level semantic variation operator.

\subsection{The Evolutionary Loop and Interface Contract}
Candidate algorithms are generated as stateless Python classes satisfying the standardized operational contract:
\begin{equation}\label{eq:operational_interface}
    \mathbf{x}^* = \operatorname{solve}(f, \text{dim}, \text{budget}, \text{lower\_bound}, \text{upper\_bound})
\end{equation}
During synthesis, candidate algorithms query the corrupted black-box wrapper $f_{\text{noisy}}(\mathbf{x})$ over an allocation of $B_{\text{synth}} = 1{,}000$ function calls. The candidate's true performance is scored by querying the ground-truth oracle at its returned coordinate: $\Delta y = |f_{\text{clean}}(\mathbf{x}^*) - f^*|$. The population iterates over $G = 10$ generations using elite preservation. For each problem instance, dimensionality, model tier, and prompt configuration, the best-performing code is saved to \texttt{db.sqlite3}.

\subsection{Prompt Scaffolding Archetypes}
To evaluate how semantic inductive biases influence algorithmic discovery, four distinct prompt scaffolding strategies were deployed as independent experimental treatments:

\begin{enumerate}
    \item \textbf{\textsc{Baseline} (Unguided Control):} Supplies strictly the operational API contract, parameter boundaries ($[-5.0, 5.0]^D$), and evaluation budget. It contains zero domain hints regarding landscape topology or the presence of evaluation noise, measuring the LLM's unassisted capacity to discover search mechanisms.
    
    \item \textbf{\textsc{Guided} (Domain-Informed Prior):} Informs the model of evaluation uncertainty and suggests foundational continuous optimization primitives, including 1/5th success-rule step adaptation, momentum buffers, population variance preservation, and exponential moving averages.
    
    \item \textbf{\textsc{Thinking} (Chain-of-Thought Reflection):} Enforces structured pre-synthesis deliberation. The model must emit a dedicated Markdown block diagnosing parent failure modes (e.g., premature variance collapse, deceptive local attractors) and detailing its algorithmic modification plan prior to outputting Python code.
    
    \item \textbf{\textsc{Vectorization} (Architectural Array Prior):} Strictly penalizes scalar Python loops over candidate populations, mandating vectorized NumPy array broadcasting to maximize evaluation throughput and parallel coordinate perturbations.
\end{enumerate}

\section{Mathematical Formulations of Empirical Performance Metrics}\label{sec:exp_metrics}

Evaluating continuous optimization heuristics across diverse topological structures and noise regimes requires evaluation metrics that remain invariant to arbitrary function translation while providing continuous, anytime performance tracking.

\subsection{51-Target Ladder and Runtime Empirical Cumulative Distribution Functions (ECDF)}

Aggregated performance is evaluated via the Runtime ECDF over a discretized ladder of $|\Theta| = 51$ logarithmic target precisions.

\subsubsection{Target Discretization: Deterministic vs. Noise-Aware Adaptive}
\begin{enumerate}
    \item \textbf{Deterministic Target Ladder ($\sigma = 0.0$):} In clean environments, the 51 targets span 10 orders of magnitude down to machine precision:
    \begin{equation}\label{eq:clean_target_ladder}
        \Theta_{\text{clean}} = \left\{ 10^{2.0 - 0.2 \cdot k} \;\middle|\; k \in \{0, 1, \dots, 50\} \right\} = \left\{ 10^{2.0}, 10^{1.8}, \dots, 10^{-8.0} \right\}
    \end{equation}
    
    \item \textbf{Noise-Aware Adaptive Target Ladder ($\sigma > 0.0$):} Under heteroscedastic noise ($\sigma = 0.05$), errors below $\Delta y \approx 10^{-3}$ fall beneath the stochastic noise floor. Enforcing static $10^{-8}$ targets under noise induces artificial \textbf{floor compression}, where over 30 targets are fundamentally unreachable and squish all ECDF curves below $\approx 0.35$. To preserve discriminatory resolution, the target ladder dynamically spans the observable empirical error range:
    \begin{equation}\label{eq:adaptive_target_ladder}
        \Theta_{\text{adaptive}}(\sigma) = \left\{ 10^{\log_{10}(\tau_{\min}) + k \cdot \frac{\log_{10}(\tau_{\max}) - \log_{10}(\tau_{\min})}{50}} \;\middle|\; k \in \{0, 1, \dots, 50\} \right\}
    \end{equation}
    where $\tau_{\min} = \max(\operatorname{Percentile}_{5}(\text{final errors}), 10^{-3})$ and $\tau_{\max} = \min(\operatorname{Median}(\text{initial errors}), 10^4)$.
\end{enumerate}

\subsubsection{Multi-Run Aggregation Mechanics (No Cherry-Picking)}
Let $T_r(f_p, \theta)$ denote the first-hitting evaluation count where run $r \in \{1 \dots N_{\text{runs}}\}$ on problem $f_p$ reaches an uncorrupted optimality gap $\Delta y \le \theta$:
\begin{equation}\label{eq:first_hitting_time}
    T_r(f_p, \theta) = \min \left\{ t \in [1, B_{\text{eval}}(D)] \;\middle|\; \left| f_{\text{clean}}(\mathbf{x}_r(t)) - f^* \right| \le \theta \right\}
\end{equation}
If target $\theta$ is not reached within the allocated budget, $T_r(f_p, \theta) = \infty$. All $N_{\text{runs}} = 20$ replications are pooled simultaneously across all $|\Theta| = 51$ targets ($1{,}020$ target-run evaluation pairs per condition):
\begin{equation}\label{eq:ecdf_formula_exact}
    \operatorname{ECDF}(t) = \frac{1}{|\Theta| \cdot N_{\text{runs}}} \sum_{r=1}^{N_{\text{runs}}} \sum_{\theta \in \Theta} \mathbb{I}\left( T_r(f_p, \theta) \le t \right) \in [0, 1]
\end{equation}
where $\mathbb{I}(\cdot)$ is the discrete indicator function.

\subsection{Area Under the Runtime ECDF Curve (AUC-ECDF)}
The global anytime search efficiency across all 51 precision targets is computed by integrating the ECDF curve across the dimension-scaled logarithmic budget $u = \log_{10}(t) \in [0, \log_{10}(B_{\text{eval}}(D))]$:
\begin{equation}\label{eq:auc_ecdf_integral}
    \text{AUC-ECDF} = \frac{1}{\log_{10}(B_{\text{eval}}(D))} \int_{0}^{\log_{10}(B_{\text{eval}}(D))} \operatorname{ECDF}\left(10^u\right) \, du \in [0, 1]
\end{equation}
\begin{equation}\label{eq:auc_ecdf_percentage}
    \text{AUC-ECDF (\%)} = \text{AUC-ECDF} \times 100\%
\end{equation}

\subsection{Median Convergence Trajectories with Interquartile Ranges (IQR) and Dynamic Y-Zoom}
To visualize continuous search dynamics without imposing parametric normality assumptions:
\begin{enumerate}
    \item \textbf{Quantile Sampling:} Sampled across all 20 independent runs on a uniform logarithmic evaluation grid $t \in [1, B_{\text{eval}}(D)]$:
    \begin{equation}\label{eq:median_trajectory}
        \tilde{y}(t) = \operatorname{median}\left(\Delta y_1(t), \Delta y_2(t), \dots, \Delta y_{20}(t)\right)
    \end{equation}
    \begin{equation}\label{eq:iqr_ribbon}
        \operatorname{IQR}(t) = \left[ Q_{25}(t), \, Q_{75}(t) \right]
    \end{equation}
    
    \item \textbf{Data-Driven Dynamic Y-Axis Bounds:} To eliminate whitespace distortion across functions with differing dynamic ranges:
    \begin{equation}\label{eq:dynamic_y_bounds}
        y_{\min} = \max\left(0.5 \cdot \min_{s, t}(\Delta y), \, 10^{-16}\right), \quad y_{\max} = 2.5 \cdot \max_{s, t}(\Delta y)
    \end{equation}
    \begin{equation}\label{eq:dynamic_y_range}
        \text{Range}_Y = \left[ \log_{10}(y_{\min}), \, \log_{10}(y_{\max}) \right]
    \end{equation}
\end{enumerate}

\subsection{Non-Parametric Hypothesis Testing and Vargha-Delaney Effect Size ($\hat{A}_{12}$)}
Pairwise comparisons between solver $i$ and solver $j$ are quantified using the non-parametric \textbf{Vargha-Delaney $\hat{A}_{12}$ Effect Size}:
\begin{equation}\label{eq:vargha_delaney_formulation}
    \hat{A}_{12}(i, j) = \frac{R_1 - \frac{n_1(n_1 + 1)}{2}}{n_1 \cdot n_2}
\end{equation}
where $R_1$ is the rank sum of solver $i$, and $n_1 = n_2 = 20$. The statistic $\hat{A}_{12} > 0.50$ indicates that solver $i$ stochastically dominates solver $j$, with $\hat{A}_{12} \ge 0.71$ denoting a large positive effect size. Statistical significance is confirmed via two-sided **Wilcoxon Signed-Rank tests** adjusted with **Benjamini-Hochberg False Discovery Rate (FDR)** corrections ($\alpha = 0.05$).

\subsection{Primary RQ1: Autonomous Synthesis and Competitiveness on Clean Landscapes}
Under deterministic conditions ($\sigma = 0.0$), LLM-synthesized heuristics demonstrate state-of-the-art continuous optimization capabilities. The synthesized champion \texttt{14B / Guided} achieved a **$78.67\%$ clean target success rate**, significantly outperforming CMA-ES ($65.33\%$), PSO ($42.67\%$), and Differential Evolution ($0.00\%$). 

On unimodal and moderate conditioning landscapes ($f_1$ Sphere and $f_8$ Rosenbrock), $14\text{B}$ LLM heuristics exhibited steeper initial convergence slopes than PSO, reaching machine precision ($\Delta y \le 10^{-8}$) within fewer function evaluations. On highly ill-conditioned problems ($f_{11}$ Discus), CMA-ES maintained its dominance due to exact analytical covariance matrix updates, whereas synthesized algorithms relied on heuristic coordinate-aligned adaptations.

\subsection{Primary RQ2: Noise Resilience in Autonomous Design}
Introducing heteroscedastic noise ($\sigma = 0.05$) revealed distinct behavioral regimes. Heuristics possessing implicit population inertia exhibited strong noise resistance: classical PSO decayed by only $\Delta_{\text{noise}} = -5.34\%$, while \texttt{14B / Baseline} exhibited a moderate drop of $-20.67\%$ (retaining a $35.33\%$ success rate under noise). Conversely, \texttt{14B / Guided}, which relied on aggressive deterministic step-size decay schedules, suffered a severe degradation ($\Delta_{\text{noise}} = -61.53\%$). This demonstrates that in the absence of explicit sample-averaging buffers ($K \ge 3$) or stochastic re-evaluation routines, aggressive descent heuristics become trapped in stochastic local basins.

\subsection{Primary RQ3: Cross-Environment Robustness and Transfer}
Heuristics evolved within noisy synthesis regimes demonstrated high cross-environment transferability when deployed back onto clean objective surfaces. Stochastic training pressure acted as an algorithmic regularizer, preventing brittle coordinate-wise overfitting and encouraging exploratory step-size mechanisms.

\subsection{Sub-RQ A: Model Parameter Capacity Scaling (14B vs. 7B vs. 3B)}
Model capacity exerted a dominant influence on synthesis capability. Moving from $7\text{B}$ to $14\text{B}$ parameters yielded a **$2.13\times$ increase in clean success rate** (averaging $56.5\%$ across $14\text{B}$ models versus $26.5\%$ across $7\text{B}$ models). Code audits in Stage 3 revealed that while $3\text{B}$ and $7\text{B}$ models primarily synthesized basic random walks or naive local hill-climbers, $14\text{B}$ models consistently generated sophisticated search components, including adaptive momentum buffers, orthogonal exploration directions, and dynamic step-size decay.

\subsection{Sub-RQ B: Prompt Scaffolding Ablation}
Prompt design significantly altered evolutionary outcomes. \textsc{Guided} scaffolding produced the highest peak performance across all model scales ($78.67\%$ on $14\text{B}$, $38.00\%$ on $7\text{B}$). \textsc{Thinking} prompts enforced structured pre-synthesis deliberation that reduced premature stagnation relative to unguided baselines, while \textsc{Vectorization} prompts improved execution throughput but occasionally constrained sequential adaptive logic.

\subsection{Sub-RQ C: Budget and Dimensionality Generalization}
Heuristics synthesized under low budgets ($B_{\text{synth}} = 1{,}000$) scaled seamlessly to full-scale benchmarking budgets ($B_{\text{eval}}(D) = 10{,}000 \times D$, up to $100{,}000$ evaluations in $10\text{D}$) without asymptotic stalling or numerical divergence. This confirms that the evolutionary discovery engine synthesizes generalizable metaheuristic policies rather than horizon-overfitted routines.
