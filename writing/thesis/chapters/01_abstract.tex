\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Continuous black-box optimization provides the computational machinery for hardware parameter extraction and physical engineering simulations. Classical derivative-free metaheuristics struggle when objective feedback contains stochastic noise. In applied settings, physical sensor errors and finite measurement precision introduce rank inversions, distorting population-based descent updates and causing premature step-size stagnation far from the global minimizer. Hand-crafting specialized filtering logic for each target domain demands extensive developer hours. Automated Algorithm Design (AAD) offers an alternative by treating the search heuristic itself as an optimizable artifact.

This thesis investigates whether Large Language Models (LLMs) embedded in an evolutionary generation loop can synthesize complete, noise-resilient Python optimizers. Using the Large Language Model Evolutionary Algorithm (LLaMEA) as our operational framework, we model the LLM as a semantic variation operator inside a $(1+1)$ Evolution Strategy. To drive code adaptation, candidate algorithms are evaluated inside a sandboxed environment against continuous Black-Box Optimization Benchmark (BBOB) instances subjected to an optimality-gap heteroscedastic noise model. The evaluation wrapper returns raw execution tracebacks and performance profiles into the prompt history to guide reflective debugging across 20-generation horizons. To prevent deceptive noise outliers from permanently stalling the selection loop, we introduce a stochastic parent resampling policy ($K=3$) that eliminates false elitist retention.

We evaluate evolved heuristics across 30 independent random seed replicates using Empirical Cumulative Distribution Functions (ECDFs), Area Over the Convergence Curve (AOCC), and non-parametric Mann-Whitney $U$ tests paired with Vargha-Delaney $\hat{A}_{12}$ effect sizes. Testing across 5-dimensional BBOB functions ($f_1, f_8, f_{10}, f_{15}, f_{21}$) and zero-shot transfers to 10D and 20D spaces measures whether closed-loop generative selection drives foundation models to invent genuine variance-filtering mechanisms rather than overfit to static coordinate distributions.
