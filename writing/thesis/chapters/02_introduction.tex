\chapter{Introduction}\label{chap:intro}

Continuous optimization underpins numerical physical modeling, financial parameter estimation, dynamic robotic control, and systems engineering. Historically, finding global minima in high-dimensional search spaces required domain specialists to construct rigid mathematical heuristics through empirical trial and error.

Modern engineering environments generate noisy, high-dimensional telemetry that limits the utility of static algorithms. This thesis investigates the intersection of continuous black-box optimization, fitness space uncertainty, and Large Language Models (LLMs). Embedding generative models within an automated evolutionary feedback loop allows the system to mutate executable Python scripts under stochastic evaluation noise, shifting Automated Algorithm Design (AAD) from idealized deterministic testbeds toward noisy empirical execution environments.

%-------------------------------------------------------------------------------
\section{Scalability Limits}\label{sec:intro_solvers}

Decades of numerical research yielded diverse general-purpose continuous solvers derived from analytical principles and empirical benchmarks \cite{Nelder1965, Hansen2001}. Widely deployed derivative-free heuristics include the Nelder-Mead simplex method \cite{Nelder1965}, Differential Evolution (DE) \cite{Storn1997}, Particle Swarm Optimization (PSO) \cite{Kennedy1995}, and the Covariance Matrix Adaptation Evolution Strategy (CMA-ES) \cite{Hansen2001}.

In continuous black-box settings, the algorithm minimizes a real-valued objective function $f: \mathbb{R}^D \rightarrow \mathbb{R}$ without access to analytical gradients $\nabla f(x)$ or internal mathematical formulations. Point queries form the sole information-gathering mechanism. Search surfaces exhibit steep conditioning, non-separability, and dense local optima. Consequently, the No Free Lunch theorem establishes that no single search heuristic consistently outperforms all competitors across all problem classes without domain-specific adaptation \cite{Burke2013}. Manually reprogramming update equations or tuning hyperparameter schedules for each target domain demands extensive developer labor and fails to scale across industrial use cases \cite{Burke2013}.

%-------------------------------------------------------------------------------
\section{Industrial Motivation}\label{sec:intro_motivation}

The limitations of hand-crafted heuristics become apparent in physical engineering systems. In parameter identification for electric vehicle battery packs, structural finite-element model updating, dynamic robotic calibration, and power grid state tracking, optimization routines evaluate physical hardware sensors rather than clean analytical formulas.

These hardware measurements contain thermal drift, electromagnetic noise, digital quantization limits, and external environmental turbulence. When classical metaheuristics traverse sensor-corrupted surfaces, localized variance degrades internal search trajectory tracking. Population-based algorithms sort candidate vectors to determine distribution updates. A poor coordinate vector can draw an extreme negative noise perturbation, registering a lower observed cost than an uncorrupted evaluation at the true optimum. Classical heuristics treat this stochastic spike as a genuine descent trajectory and shift mutation distributions toward false coordinates. Standard human-engineered corrections, including static sample averaging and expanded population sizing, increase function evaluation costs without guaranteeing stable convergence. These constraints motivate investigating whether automated code generators can synthesize specialized algorithmic logic that dynamically filters sensor errors.

\section{The Core Research Gap}\label{sec:intro_gap}

Early Automated Algorithm Design (AAD) and hyper-heuristic systems used Genetic Programming to assemble predefined programmatic components \cite{Burke2013, vanRijn2016}. Rigid grammar rules and finite component libraries restricted the expressive range of candidate search routines \cite{Burke2013}.

Large Language Models alter this generation dynamic. Modern AAD frameworks embed generative models within closed-loop execution environments that write, test, and debug complete, executable source code files \cite{Romera2023}. This research implements the Large Language Model Evolutionary Algorithm (LLaMEA) \cite{LLaMEA2024}. LLaMEA prompts a model to generate complete Python optimizer classes, runs the code within an isolated benchmarking harness, and passes execution metrics and compiler tracebacks back into the prompt context to drive iterative mutation.

Despite recent progress in frameworks such as FunSearch \cite{Romera2023}, Evolution of Heuristics (EoH) \cite{Liu2024}, and LLaMEA \cite{LLaMEA2024}, existing studies evaluate generated code almost exclusively under deterministic conditions. Candidate algorithms are evolved on noise-free mathematical functions or discrete combinatorial graphs. When a model synthesizes code under clean evaluation feedback, it generates logic optimized for exact objective values. Exposing these deterministic routines to stochastic evaluation noise induces ranking corruption and destabilizes selection. Chapter~\ref{chap:research} reviews these failure mechanics and noise taxonomies in detail.

It remains unverified whether closed-loop evolutionary prompts can force foundation models to invent uncertainty-handling logic. Furthermore, the capacity of open-weights models relative to commercial baselines and the transferability of noise-evolved heuristics to unseen deterministic functions remain uncharacterized. This thesis examines the performance and structural adaptation of LLaMEA across continuous black-box optimization functions corrupted by controlled statistical noise.

Figure~\ref{fig:intro_paradigm} outlines the closed-loop design loop evaluated in this work. The pipeline comprises three operational stages: an LLM generating candidate Python classes from interface specifications, an isolated sandbox executing the algorithms against target benchmarks, and an evaluation module logging runtime statistics and compiler tracebacks. Across generations $1 \dots N-1$, the harness feeds diagnostic metrics back into the model context to drive self-debugging and code mutation.

\section{Research Objectives}\label{sec:intro_objectives}

This thesis evaluates whether Large Language Models can synthesize continuous optimization heuristics capable of operating under stochastic fitness noise. Three research questions structure the investigation:

\subsection*{Objective 1: Formulating a Stochastic Evaluation Sandbox}
Evaluating generative models under uncertainty requires transforming deterministic benchmark suites into controlled stochastic surfaces:

\begin{quote}
\textbf{RQ1: How can continuous optimization benchmarks be systematically extended to simulate stochastic landscapes?}
\end{quote}

This phase constructs a non-deterministic software wrapper around standardized continuous benchmark functions \cite{Jin2005, Hansen2009Noisy}. We implement parameter-controlled statistical noise distributions over objective evaluations. The wrapper isolates the candidate optimizer from exact analytical metrics, generating the selection pressure necessary to evaluate stochastic adaptation during code generation.

\subsection*{Objective 2: Autonomous Synthesis of Noise-Resilient Heuristics}
Prior studies confirm that generative loops discover competitive optimizers for noiseless functions. Whether language models adapt their code structures under stochastic disruption remains an open question:

\begin{quote}
\textbf{RQ2: Can Large Language Models, across open-weights and proprietary architectures, autonomously synthesize optimization heuristics that are resilient to noise?}
\end{quote}

We deploy the LLaMEA framework across continuous benchmark functions using both open-weights models and commercial API baselines. The harness routes runtime tracebacks back to the context window across successive generations. By analyzing structural modifications in the generated Python classes, we evaluate whether closed-loop selection guides the LLMs to write dedicated variance-filtering mechanisms.

\subsection*{Objective 3: Empirical Benchmarking and Cross-Environment Analysis}
Characterizing evolved heuristics requires measuring solution precision and convergence rates across varying noise settings:

\begin{quote}
\textbf{RQ3: How does the cross-environment robustness of noise-evolved heuristics compare against noiseless baselines?}
\end{quote}

We benchmark the champion algorithms against control variants evolved on clean surfaces and classical baselines, including CMA-ES and Differential Evolution. Testing these solvers across identical stochastic conditions isolates the performance difference attributable to noise-aware evolution. Finally, we compare empirical convergence profiles against baseline literature to establish the structural boundaries of LLM-generated search logic under uncertainty.

\section{Summary of Key Contributions}\label{sec:intro_contributions}

This research evaluates Automated Algorithm Design under physical measurement constraints. The primary contributions comprise:

\begin{enumerate}
    \item \textbf{Stochastic Benchmark Sandbox Environment:} An extensible evaluation wrapper built over continuous BBOB benchmark functions. The software injects parameter-controlled statistical noise directly into objective queries, establishing a standardized harness for testing algorithms under fitness space uncertainty.
    
    \item \textbf{Closed-Loop Autonomous Discovery Pipeline:} An implementation extending LLaMEA to stochastic environments. The system routes compiler tracebacks and empirical convergence data back to open-weights and proprietary foundation models to drive automated code mutation.
    
    \item \textbf{Comprehensive Empirical Robustness Evaluation:} A systematic benchmarking suite comparing LLM-generated heuristics against clean-evolved control models and classical solvers (CMA-ES, Differential Evolution). The evaluation tracks solution quality, runtime convergence, and programmatic syntax under non-deterministic conditions.
\end{enumerate}

\section{Scope and Limitations}\label{sec:intro_scope}

The operational boundaries of this thesis are defined as follows:

\begin{itemize}
    \item \textbf{Problem Domain:} The study focuses on unconstrained, single-objective continuous black-box problems $f: \mathbb{R}^D \rightarrow \mathbb{R}$. To manage compute budgets during iterative LLM generation, we select five representative functions from the Black-Box Optimization Benchmark (BBOB) suite covering separable, ill-conditioned, and multi-modal geometries ($f_1, f_8, f_{10}, f_{15}, f_{21}$). Combinatorial, multi-objective, and explicitly constrained optimization problems remain outside this scope.
    
    \item \textbf{Noise Taxonomy:} Uncertainty is restricted to stochastic noise in the objective fitness space. We apply a landscape-scaled additive Gaussian noise model. Before optimization starts, the baseline scale $S$ is estimated by sampling the mean absolute deviation of uniformly distributed points from the known minimum. Additive Gaussian noise is injected as $\mathcal{N}(0, (\gamma \cdot S)^2)$, where $\gamma$ controls the standard deviation multiplier. This formulation scales noise variance relative to the objective range. Parameter uncertainty in coordinate vectors $x$ and time-varying dynamic environments are excluded.
    
    \item \textbf{Evaluation Limits:} Fixed function evaluation budgets and generational limits cap each LLaMEA execution run, managing API token expenditure and compute latency.
\end{itemize}

\section{Thesis Outline}\label{sec:intro_outline}

The thesis is organized as follows:

\begin{itemize}
    \item \textbf{Chapter~\ref{chap:research} (Related Work):} Reviews continuous black-box optimization, classical metaheuristics, mathematical noise models, and the progression of Automated Algorithm Design from Genetic Programming to reflective LLM systems.
    \item \textbf{Chapter~\ref{chap:methodology} (Methodology):} Details the orchestration architecture, the non-deterministic sandbox, the $(1+1)$ Evolution Strategy in LLaMEA, model selection, and prompt context specifications.
    \item \textbf{Chapter~\ref{chap:experiments} (Experiments and Results):} Presents quantitative benchmark data, Empirical Cumulative Distribution Functions (ECDFs), anytime convergence trajectories, cross-environment transfer results, and code inspections of generated algorithms.
    \item \textbf{Chapter~\ref{chap:discussion} (Discussion and Conclusion):} Discusses empirical findings, compares token and compute costs between open and commercial architectures, addresses system limitations, and outlines directions for future algorithm discovery pipelines.
\end{itemize}
