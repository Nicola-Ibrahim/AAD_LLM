\chapter{Methodology}\label{chap:methodology}

Deploying Large Language Models to generate noise-resilient continuous optimizers requires restructuring the evaluation harness. Standard evolutionary loops suffer from fitness deception when objective evaluations contain stochastic variance. The execution environment must filter this variance while preserving the feedback needed for programmatic mutation. The architecture developed in this thesis decouples candidate exploration feedback from internal benchmark tracking within an automated design loop.

The chapter builds from core mathematical components up to system orchestration. First, it defines the optimality-gap heteroscedastic noise model. Second, it specifies the sandboxed execution environment and Abstract Syntax Tree (AST) validation rules. Third, it formalizes the evolutionary selection mechanics alongside the parent resampling policy. Fourth, it outlines four distinct prompt scaffolding configurations. Finally, it presents the complete pipeline execution flow and the statistical testing protocols used for empirical validation.

\section{The Stochastic Sandbox and Optimality-Gap Heteroscedastic Noise}\label{sec:method_sandbox}

Evaluating whether generative models can discover noise-tolerant optimization heuristics requires testing candidate code against non-deterministic objective functions \cite{Jin2005}. This work uses the continuous Black-Box Optimization Benchmark (BBOB) suite as its foundational testbed \cite{Hansen2010}. Because the base BBOB functions are deterministic, evaluating stochastic resilience requires injecting noise at the evaluation wrapper level.

Stochastic optimization literature commonly introduces uncertainty through static additive Gaussian noise \cite{Jin2005}:
\begin{equation}\label{eq:static_noise_lit}
    f_{\text{noisy}}(x) = f_{\text{clean}}(x) + \mathcal{N}(0, \sigma^2)
\end{equation}
or through point-wise multiplicative noise \cite{Jin2005}:
\begin{equation}\label{eq:naive_multiplicative_lit}
    f_{\text{noisy}}(x) = f_{\text{clean}}(x) \cdot \left(1 + \mathcal{N}(0, \text{CV}^2)\right)
\end{equation}
where $x \in \mathbb{R}^D$ denotes a $D$-dimensional coordinate vector, $f_{\text{clean}}(x) \in \mathbb{R}$ is the uncorrupted objective value, $\sigma^2 \in \mathbb{R}^+$ is a fixed variance, $\text{CV} \in \mathbb{R}^+$ is the dimensionless Coefficient of Variation ($\text{CV} = \sigma / \mu$), and $f_{\text{noisy}}(x) \in \mathbb{R}$ is the noisy value returned to the search heuristic.

Both formulations exhibit severe structural flaws across heterogeneous benchmark suites \cite{Hansen2010}. Static noise (Equation~\ref{eq:static_noise_lit}) applies a fixed variance $\sigma^2$ regardless of functional scale. On flat surfaces where objective values near the minimum approach $10^{-5}$, fixed variance drowns out the true gradient. Conversely, when objective values reach $10^6$ on steep surfaces, the same variance constitutes a negligible fraction of the local gradient, allowing algorithms to optimize without developing noise-filtering behavior \cite{Hansen2010}.

Multiplicative noise (Equation~\ref{eq:naive_multiplicative_lit}) introduces a different artifact: it scales variance with the raw coordinate value $f_{\text{clean}}(x)$. The raw evaluation includes any arbitrary vertical offset $f(x^*)$ added to the global minimum, which carries no information about the spatial distance to the target. Shifting a function vertically via $g(x) = f(x) + 10\,000$ multiplies the noise variance by orders of magnitude, destroying the underlying basin geometry.

BBOB Function $f_{21}$ (Gallagher's Gaussian 101 Peaks) illustrates this distortion directly. The global minimum has an offset of $f(x^*) \approx 40.78$, and the total dynamic range spans approximately 50 units (between 40 and 90). Under multiplicative noise with $\text{CV} = 0.05$, evaluating a candidate point in the optimal basin at $f_{\text{clean}}(x) = 41.0$ yields a standard deviation of:
\begin{equation}\label{eq:f21_naive_std}
    \sigma = 0.05 \cdot 41.0 = 2.05
\end{equation}
A variation of $\pm 2.05$ covers 4\% of the function's entire range. On a multimodal surface where local peak differences range between 2 and 5 units, this variance erases local basin distinctions. Evaluating two nearby candidate vectors $x_a$ ($f = 41.5$) and $x_b$ ($f = 42.0$) generates heavily overlapping distributions: $f_{\text{noisy}}(x_a) \sim \mathcal{N}(41.5, 2.075^2)$ and $f_{\text{noisy}}(x_b) \sim \mathcal{N}(42.0, 2.1^2)$. The resulting sample draws invert the true ranking and obscure the local gradient.

Pure multiplicative noise also creates an uncorrupted zone near zero-valued minima. As search coordinates approach $f(x^*) = 0$, local variance vanishes:
\begin{equation}\label{eq:vanishing_variance}
    \lim_{f(x) \to f(x^*)} \operatorname{Var}\left(f_{\text{noisy}}(x)\right) = 0
\end{equation}
where $\operatorname{Var}(\cdot)$ denotes the variance operator. Algorithms near convergence receive noise-free feedback, which circumvents the stochastic requirements of the benchmark.

To correct these issues, this thesis formulates the \textbf{Optimality-Gap Heteroscedastic Noise Model with a Non-Zero Baseline Noise Floor}. Rather than scaling variance by raw function values, the formulation ties variance directly to the true optimality gap. For an evaluation coordinate $x_k \in \mathbb{R}^D$ sampled at step $k$, the local standard deviation $\sigma_{\text{dynamic}}(x_k)$ is proportional to the distance from the known global minimum $f(x^*)$, bound by a lower threshold $\sigma_{\text{floor}} > 0$:
\begin{equation}\label{eq:proportional_dynamic_std}
    \sigma_{\text{dynamic}}(x_k) = \text{CV} \cdot \left| f_{\text{clean}}(x_k) - f(x^*) \right| + \sigma_{\text{floor}}
\end{equation}
where $\text{CV} \ge 0$ specifies the relative noise magnitude, $\left| f_{\text{clean}}(x_k) - f(x^*) \right|$ is the true functional distance to the optimum, and $\sigma_{\text{floor}} = 10^{-8}$ prevents the variance from dropping to zero at the minimum.

The benchmark harness stores the analytical minimum $f(x^*)$ internally while hiding it from the candidate algorithm. The noisy observation returned to the candidate optimizer at step $k$ is:
\begin{equation}\label{eq:proportional_gaussian_noise}
    f_{\text{noisy}}(x_k) = f_{\text{clean}}(x_k) + z_k, \quad z_k \sim \mathcal{N}\left(0, \sigma_{\text{dynamic}}^2(x_k)\right)
\end{equation}
where $z_k \in \mathbb{R}$ is an independent zero-mean Gaussian perturbation sampled at step $k$. The probability density function $p(z_k)$ governing this perturbation is:
\begin{equation}\label{eq:gaussian_pdf_dynamic}
    p(z_k) = \frac{1}{\sqrt{2\pi \sigma_{\text{dynamic}}^2(x_k)}} \exp\left( -\frac{z_k^2}{2\sigma_{\text{dynamic}}^2(x_k)} \right)
\end{equation}
Because $p(z_k)$ is symmetric around zero with $\mathbb{E}[z_k] = 0$, the expected value of the noisy observation matches the uncorrupted evaluation:
\begin{equation}\label{eq:unbiased_expectation}
    \mathbb{E}[f_{\text{noisy}}(x_k)] = f_{\text{clean}}(x_k)
\end{equation}

Tying evaluation variance to the optimality gap provides three properties:
\begin{enumerate}
    \item \textbf{Oracle Preservation:} As candidate coordinates approach the global minimum ($f_{\text{clean}}(x) \to f(x^*)$), the variance converges to $\sigma_{\text{floor}} = 10^{-8}$. The global optimum remains distinguishable across all noise settings.
    \item \textbf{Scale-Invariance:} The Signal-to-Noise Ratio (SNR) remains bounded by $1/\text{CV}$ across varying function ranges, from $f_8$ (range $\sim 10^3$) to $f_{21}$ (range $\sim 50$). This avoids per-function noise parameter retuning.
    \item \textbf{Structured Difficulty:} Regions distant from the minimum exhibit high variance, while coordinates close to the target exhibit lower variance. This matches empirical engineering scenarios where measurement error scales with deviation from a target equilibrium state.
\end{enumerate}

Applying this gap-anchored model ($\text{CV} = 0.05$) to the $f_{21}$ test case, the sample coordinates $x_a$ ($f = 41.5$) and $x_b$ ($f = 42.0$) yield standard deviations of:
\begin{equation}\label{eq:f21_gap_std_a}
    \sigma_{\text{dynamic}}(x_a) = 0.05 \cdot |41.5 - 40.78| + 10^{-8} \approx 0.036
\end{equation}
\begin{equation}\label{eq:f21_gap_std_b}
    \sigma_{\text{dynamic}}(x_b) = 0.05 \cdot |42.0 - 40.78| + 10^{-8} \approx 0.061
\end{equation}
The resulting distributions, $f_{\text{noisy}}(x_a) \sim \mathcal{N}(41.5, 0.036^2)$ and $f_{\text{noisy}}(x_b) \sim \mathcal{N}(42.0, 0.061^2)$, preserve the underlying ranking between both points and maintain a usable descent signal.

To examine these mechanics on an ill-conditioned landscape, consider BBOB Function $f_8$ (Rosenbrock). Benchmark instances apply spatial translations $x^* \in \mathbb{R}^D$ and rotation matrices $R \in \mathbb{R}^{D \times D}$ to remove coordinate-axis alignment \cite{Hansen2010}. The analytical formulation is:
\begin{equation}\label{eq:bbob_f8_formula}
    f_8(x) = \sum_{i=1}^{D-1} \left[ 100 \cdot \left( y_{i+1} - y_i^2 \right)^2 + (1 - y_i)^2 \right] + f_{\text{opt}}
\end{equation}
where $y \in \mathbb{R}^D$ is the transformed coordinate vector $y = \max\left(1, \frac{\sqrt{D}}{8}\right) R (x - x^*) + \mathbf{1}$, $\mathbf{1} \in \mathbb{R}^D$ is a vector of ones, and $f_{\text{opt}} \in \mathbb{R}$ is the minimum value.

The quadratic term $100 \cdot (y_{i+1} - y_i^2)^2$ forms a narrow curved valley across the search space (Figure~\ref{fig:f8_3d_landscape}), pushing deviations $f_{\text{clean}}(x_k) - f_{\text{opt}}$ up to $10^3$ near domain boundaries.

Under the gap-anchored model with $\text{CV} = 0.1$, exploration at the outer boundary where $f_{\text{clean}}(x_k) - f_{\text{opt}} \approx 10^3$ sets the noise standard deviation to:
\begin{equation}\label{eq:f8_dynamic_std_boundary}
    \sigma_{\text{dynamic}}(x_k) = 0.1 \cdot 10^3 + 10^{-8} \approx 10^2
\end{equation}
Once search points enter the parabolic valley where $f_{\text{clean}}(x_k) - f_{\text{opt}} \approx 10^1$, the standard deviation scales down accordingly:
\begin{equation}\label{eq:f8_dynamic_std_valley}
    \sigma_{\text{dynamic}}(x_k) = 0.1 \cdot 10^1 + 10^{-8} \approx 10^0
\end{equation}
By comparison, evaluating the isotropic sphere function $f_1(x) = \|R(x - x^*)\|^2 + f_{\text{opt}}$ near domain boundaries produces objective differences of $f_{\text{clean}}(x_k) - f_{\text{opt}} \approx 10^1$, yielding $\sigma_{\text{dynamic}} \approx 10^0$.

Injecting these variance values into Equation~\ref{eq:proportional_gaussian_noise} yields perturbations $z_k \sim \mathcal{N}(0, \sigma_{\text{dynamic}}^2(x_k))$ that maintain equivalent SNR across diverse topological surfaces.

\section{Dual-Evaluation Decoupling and Distance-to-Optimum Tracking}\label{sec:method_decoupling}

The evaluation framework separates the noisy feedback passed to the candidate algorithm from the ground-truth metrics used for performance tracking. Candidate routines require noisy feedback $f_{\text{noisy}}(x_k)$ to drive the development of internal filtering logic. However, logging noisy evaluations directly would distort empirical benchmarking, because a candidate could receive an extreme negative noise draw ($z_k \ll 0$) that falsely indicates convergence. Algorithms rely on $f_{\text{noisy}}(x_k)$ for coordinate updates, while the background logger computes the uncorrupted distance to the optimum:
\begin{equation}\label{eq:clean_distance_metric}
    \Delta f(x_k) = f_{\text{clean}}(x_k) - f(x^*)
\end{equation}
where $\Delta f(x_k) \in \mathbb{R}^+$ denotes the true distance between coordinate $x_k$ and the global minimizer $f(x^*)$.

Over a budget of $B = 100\,000$ evaluations, the runtime progress of algorithm $\mathcal{A}$ is logged by recording the lowest uncorrupted error achieved up to step $k$:
\begin{equation}\label{eq:best_so_far_trajectory}
    \Delta f_{\text{best}}(k) = \min_{j \in \{1 \dots k\}} \left( f_{\text{clean}}(x_j) - f(x^*) \right)
\end{equation}
This separation ensures that convergence plots reflect actual spatial minimization rather than stochastic measurement noise.

\section{Execution Sandbox Defenses and Diagnostic Scoring}\label{sec:method_sandbox_defenses}

Autonomous algorithm generation requires isolating the host operating system from untrusted model-generated code. Unconstrained models occasionally output malformed syntax or non-executable conversational text. The pipeline handles this through strict parsing boundaries.

Generated outputs pass through a regular-expression extraction filter that isolates the executable Python block from conversational text. The isolated block is parsed through an Abstract Syntax Tree (AST) validator. This validator accepts standard numerical packages (\texttt{numpy}, \texttt{scipy}) while blocking system access libraries (\texttt{os}, \texttt{sys}, \texttt{subprocess}), preventing unauthorized process calls.

To handle infinite loops or stalled iterations, the harness enforces a 10-second wall-clock timeout per run. When an algorithm exceeds this limit, the execution worker is terminated and marked as failed.

Mutated algorithms also encounter mathematical runtime exceptions, including singular matrix inversions, dimensional broadcasting mismatches, and numerical overflow. When an exception occurs, the sandbox captures the Python traceback and assigns the worst possible fitness score ($\text{Fitness} = +\infty$). The full traceback string is appended to the feedback context $\mathcal{T}_{\text{feedback}}$ for the subsequent generation. Returning the runtime error trace directly to the model closes the self-debugging loop across the 20-generation evolutionary run.

\section{LLM-Driven Evolutionary Code Discovery and Parent Resampling}\label{sec:method_llamea}

The system adapts the Large Language Model Evolutionary Algorithm (LLaMEA) as its core search engine \cite{LLaMEA2024}. The language model acts as a semantic variation operator that refactors algorithm structure, modifies population logic, and adjusts parameter updates based on execution feedback.

The generation loop follows a single-offspring $(1+1)$ Evolution Strategy. In each generation $g \in \{1 \dots G\}$, where $G = 20$ represents the maximum generation limit, the model generates one child algorithm $\mathcal{A}_{\text{child}}$ by mutating the active parent $\mathcal{A}_{\text{parent}}$.

\subsection{The Reflective Prompt Architecture}
At generation $g$, the prompt context $\mathcal{C}_g$ is assembled from four components:
\begin{equation}\label{eq:context_assembly}
    \mathcal{C}_g = \left\{ \mathcal{P}_{\text{system}}, \mathcal{H}_{1 \dots g-1}, \mathcal{T}_{\text{feedback}}, F_0 \right\}
\end{equation}
These components contain:
\begin{enumerate}
    \item \textbf{Task Description ($\mathcal{P}_{\text{system}}$):} Defines the class interface. Generated optimizers must inherit from the base class and accept problem handles, budgets, dimensionality limits, and domain bounds.
    \item \textbf{Historical Archive ($\mathcal{H}_{1 \dots g-1}$):} Maintains an indexed log of previously tested algorithms along with their numerical scores, preventing repetitive code generation.
    \item \textbf{Incumbent Information ($\mathcal{T}_{\text{feedback}}$):} Contains the source code of the active parent algorithm, its best-so-far precision $\min_k \Delta f(x_k)$, and any runtime exceptions from previous iterations.
    \item \textbf{Directive Instruction ($F_0$):} Prompts the model to either refine current parameters or redesign the underlying algorithm structure.
\end{enumerate}

\subsection{Mitigating False Elitism: Stochastic Parent Resampling Policy}
Under noisy evaluations ($f_{\text{noisy}} = f_{\text{clean}} + z$), standard greedy selection fails due to false elitism \cite{Jin2005, Qian2020}. A sub-optimal child algorithm can draw an outlier negative noise sequence ($z \ll 0$), producing an artificially low error value. If this over-evaluated child replaces the parent, it sets an artificially strict fitness threshold. Structurally superior offspring generated in subsequent iterations are rejected because their uncorrupted scores cannot beat the outlier parent score, freezing optimization progress.

The framework counters this vulnerability with a Stochastic Parent Resampling Policy. The fitness score of an algorithm $\mathcal{A}$ over budget $B = 100\,000$ is defined by its logarithmic precision:
\begin{equation}\label{eq:individual_fitness}
    \text{Fitness}(\mathcal{A}) = \log_{10} \left( \min_{k \in \{1 \dots B\}} \Delta f(x_k) \right)
\end{equation}
At the end of each generation cycle $g$, the active parent $\mathcal{A}_{\text{parent}}$ is re-evaluated across $K=3$ independent stochastic runs. The baseline fitness is updated to the empirical mean:
\begin{equation}\label{eq:parent_resampling}
    \bar{f}_{\text{parent}} = \frac{1}{K} \sum_{k=1}^{K} \text{Fitness}^{(k)}\left(\mathcal{A}_{\text{parent}}\right)
\end{equation}
where $K = 3$ is the number of re-evaluation passes, and $\text{Fitness}^{(k)}\left(\mathcal{A}_{\text{parent}}\right)$ is the score on pass $k$. Resampling reduces the survival time of transient noise outliers, ensuring that selection favors algorithms with structural noise resistance.

\section{Prompt Scaffolding Configurations}\label{sec:method_prompts}

To evaluate how different prompting priors influence the generation of noise-resilient logic, the methodology defines four scaffolding configurations:
\begin{enumerate}
    \item \textbf{The BASELINE Prompt:} Operates as the experimental control. It contains only the execution API requirements, with no domain hints regarding landscape topology or evaluation noise.
    \item \textbf{The THINKING Prompt:} Applies a Chain-of-Thought (CoT) pattern. The model must output an explicit analytical reasoning block evaluating prior tracebacks and score differences before generating code.
    \item \textbf{The VECTORIZATION Prompt:} Enforces matrix-oriented implementation constraints. It forbids standard scalar Python loops across population members, requiring vectorized NumPy broadcast operations.
    \item \textbf{The GUIDED Prompt:} Provides domain-specific hints. The prompt notes that evaluations contain stochastic variance and suggests techniques such as momentum updates, sample averaging, and step-size damping.
\end{enumerate}

\section{End-to-End Pipeline Orchestration}\label{sec:method_orchestration}

The mathematical noise wrapper, security filters, evolutionary selection mechanics, and prompt scaffolding integrate into an automated generation loop.

\begin{figure}[htbp]
    \centering
    \input{figures/evolutionary_aad_loop}
    \caption{System orchestration of the stochastic Automated Algorithm Design loop. Source code flows from the model through AST validation to the execution sandbox. Search decisions consume noisy evaluations $f_{\text{noisy}}(x_k)$, while the background logger records true precision $\Delta f(x_k)$ and applies parent resampling ($K=3$, $\bar{f}_{\text{parent}}$) to update prompt context $\mathcal{C}_g$.}
    \label{fig:evolutionary_aad_loop}
\end{figure}

The execution sequence proceeds through five stages per generation:
\begin{enumerate}
    \item \textbf{Context Assembly and Generation:} The driver builds prompt $\mathcal{C}_g$ (Equation~\ref{eq:context_assembly}) and queries the model to generate child code $\mathcal{A}_{\text{child}}$.
    \item \textbf{Sanitization and Validation:} The code block is extracted via regex and checked by the AST validator. Unauthorized imports cause immediate candidate rejection.
    \item \textbf{Decoupled Execution:} The candidate executes in the sandbox. Search routines receive noisy feedback $f_{\text{noisy}}(x_k)$ (Equation~\ref{eq:proportional_gaussian_noise}), while the telemetry system records the uncorrupted metric $\Delta f(x_k)$ (Equation~\ref{eq:clean_distance_metric}) over $B = 100\,000$ evaluations.
    \item \textbf{Error Handling:} If execution fails or exceeds 10 seconds, the run is assigned $\text{Fitness} = +\infty$, and the traceback is preserved for generation $g+1$.
    \item \textbf{Selection and Resampling:} If execution completes successfully, child fitness $\text{Fitness}(\mathcal{A}_{\text{child}})$ is compared against the parent. The incumbent parent is re-evaluated across $K=3$ runs to update $\bar{f}_{\text{parent}}$ (Equation~\ref{eq:parent_resampling}), after which the history log $\mathcal{H}_{1 \dots g}$ is updated.
\end{enumerate}

\section{Two-Phase Experimental Gauntlet and Cross-Validation}\label{sec:method_gauntlet}

The empirical evaluation uses a two-phase benchmarking structure to manage compute requirements.

\subsection{Phase 1: Intra-Framework Prompt Ablation}
Phase 1 evaluates the four prompt scaffolding strategies across five BBOB benchmark functions representing distinct topological classes:
\begin{itemize}
    \item \textbf{$f_1$ (Sphere):} Separable baseline for measuring unconstrained convergence rate.
    \item \textbf{$f_8$ (Rosenbrock):} Low/moderate conditioning with a curved parabolic valley.
    \item \textbf{$f_{10}$ (Ellipsoidal):} High conditioning with ill-conditioned coordinate axes.
    \item \textbf{$f_{15}$ (Rastrigin):} Multimodal surface with a strong underlying global structure.
    \item \textbf{$f_{21}$ (Gallagher 101 Peaks):} Multimodal surface with 101 local optima and weak global structure.
\end{itemize}
LLaMEA runs independently on each function under the Optimality-Gap noise model ($\text{CV} = 0.05, 0.1$) to identify the best-performing algorithm per prompt setting.

\subsection{Phase 2: Baseline Benchmarking and Dimensional Transfer}
Phase 2 compares the champion algorithms from Phase 1 against three human-designed baselines: Covariance Matrix Adaptation Evolution Strategy (CMA-ES) \cite{Hansen2001}, Differential Evolution (DE) \cite{Storn1997}, and Particle Swarm Optimization (PSO) \cite{Kennedy1995}.

The evaluation tests two conditions:
\begin{enumerate}
    \item \textbf{Deterministic Evaluation ($\text{CV} = 0$):} Tests whether algorithms evolved under noise maintain optimization performance on clean objective surfaces.
    \item \textbf{Stochastic Evaluation ($\text{CV} > 0$):} Measures the performance degradation of classical baselines relative to the noise-evolved optimizers under increasing variance.
\end{enumerate}
To assess structural scalability, algorithms evolved on 5-dimensional (5D) problems are tested on 10D and 20D instances of the same problem classes without code modifications.

\section{Empirical Evaluation Metrics and Statistical Protocols}\label{sec:method_stats}

Each algorithm configuration is evaluated over $N_{\text{trials}} = 30$ independent random seeds. Performance is tracked using anytime convergence profiles and non-parametric Empirical Cumulative Distribution Functions (ECDFs) \cite{Hansen2021COCO, deNobel2024}.

\subsection{Anytime Convergence Trajectory Analysis}
Anytime curves track optimization error as a function of the expended evaluation budget. Let $x_k \in \mathbb{R}^D$ be the coordinate queried at step $k \in \{1 \dots B\}$, with budget $B = 100\,000$. The candidate algorithm uses noisy observations $f_{\text{noisy}}(x_k)$, while the logging layer records the true error:
\begin{equation}\label{eq:clean_delta_step}
    \Delta f(x_k) = f_{\text{clean}}(x_k) - f(x^*)
\end{equation}
where $f(x^*) \in \mathbb{R}$ is the theoretical minimum.

The anytime metric tracks the lowest true error found up to evaluation $k$:
\begin{equation}\label{eq:best_so_far_trajectory_eval}
    \Delta f_{\text{best}}(k) = \min_{j \in \{1 \dots k\}} \left( f_{\text{clean}}(x_j) - f(x^*) \right)
\end{equation}
Across 30 runs, results are summarized using geometric mean trajectories and standard error bands on logarithmic axes:
\begin{itemize}
    \item \textbf{Horizontal Axis ($k$):} Function evaluations on a logarithmic scale from $1$ to $10^5$.
    \item \textbf{Vertical Axis ($\Delta f_{\text{best}}(k)$):} True distance to the minimum from $10^6$ down to $10^{-8}$.
    \item \textbf{Stagnation Analysis:} Horizontal asymptotic plateaus mark the budget threshold where an algorithm halts progress due to step-size collapse or ranking errors.
\end{itemize}

\subsection{Empirical Cumulative Distribution Functions (ECDFs)}
Empirical Cumulative Distribution Functions aggregate target attainment rates across precision thresholds \cite{Hansen2021COCO}.

Let $\mathcal{T}$ represent a set of $M$ logarithmically spaced target precision levels:
\begin{equation}\label{eq:target_precision_spectrum}
    \mathcal{T} = \left\{ \tau \in \mathbb{R}^+ \mid 10^{-8} \le \tau \le 10^2 \right\}
\end{equation}
For $N_{\text{trials}}$ independent runs, the empirical attainment function at target precision $\tau \in \mathcal{T}$ is:
\begin{equation}\label{eq:ecdf_formula}
    F(\tau) = \frac{1}{N_{\text{trials}}} \sum_{i=1}^{N_{\text{trials}}} \mathbb{I}\left[ \Delta f_{\text{best}}^{(i)}(B) \le \tau \right]
\end{equation}
where $\Delta f_{\text{best}}^{(i)}(B) = \min_{k \le B} (f_{\text{clean}}^{(i)}(x_k) - f(x^*))$ is the terminal residual on trial $i$, and $\mathbb{I}[\cdot]$ is the indicator function:
\begin{equation}\label{eq:indicator_function}
    \mathbb{I}\left[ \Delta f_{\text{best}}^{(i)}(B) \le \tau \right] = 
    \begin{cases} 
        1, & \text{if } \Delta f_{\text{best}}^{(i)}(B) \le \tau \\ 
        0, & \text{if } \Delta f_{\text{best}}^{(i)}(B) > \tau 
    \end{cases}
\end{equation}

The step function characterizes overall solver reliability:
\begin{itemize}
    \item \textbf{Step Increments:} With finite samples $N_{\text{trials}}$, the empirical CDF rises in steps of $1/N_{\text{trials}}$ ($1/30 \approx 3.33\%$) at each recorded residual.
    \item \textbf{Precision Axis ($\tau$):} The horizontal axis sweeps from loose tolerances ($\tau \ge 1$) to strict tolerances ($\tau \le 10^{-4}$).
    \item \textbf{Attainment Proportion ($F(\tau)$):} The vertical axis indicates the fraction of runs ($0.0 \le F(\tau) \le 1.0$) reaching threshold $\tau$ within budget $B$.
    \item \textbf{Comparison Criteria:} Curves positioned toward the upper-left indicate higher success rates at strict precision limits.
\end{itemize}

\subsection{Non-Parametric Hypothesis Testing and Effect Size}
Because optimization residuals under stochastic noise are non-normal and heavily skewed, parametric tests like Student's t-test are inapplicable. Differences between candidate algorithms and baseline solvers are evaluated using the non-parametric \textbf{Mann-Whitney U Test} \cite{MannWhitney1947} with significance set at $\alpha = 0.05$.

Performance margins are quantified using the \textbf{Vargha-Delaney $\hat{A}_{12}$} effect size metric \cite{VarghaDelaney2000}. The $\hat{A}_{12}$ index gives the probability that a run from the champion algorithm ($\mathcal{A}_1$) yields a lower terminal error than a run from baseline ($\mathcal{A}_2$):
\begin{equation}\label{eq:vargha_delaney}
    \hat{A}_{12} = \frac{R_1}{n_1 n_2} - \frac{n_1 + 1}{2 n_2}
\end{equation}
where $R_1$ is the rank sum of the champion runs within the pooled ranking, and $n_1 = n_2 = 30$ are the group sample sizes.

The statistic $\hat{A}_{12} \in [0, 1]$ maps to standard effect size intervals \cite{VarghaDelaney2000}:
\begin{itemize}
    \item $\hat{A}_{12} = 0.50$: Stochastic equivalence between solvers.
    \item $\hat{A}_{12} > 0.50$: Superiority of the champion algorithm over the baseline.
    \item $\hat{A}_{12} \ge 0.56$: Small effect size.
    \item $\hat{A}_{12} \ge 0.64$: Medium effect size.
    \item $\hat{A}_{12} \ge 0.71$: Large effect size.
\end{itemize}
