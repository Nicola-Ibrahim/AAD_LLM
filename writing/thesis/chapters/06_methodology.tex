\chapter{Methodology}\label{chap:methodology}

This chapter details the architectural design, software orchestration, and mathematical formulation of the non-deterministic automated algorithm design pipeline implemented in this thesis. To isolate the adaptive mechanics of Large Language Model (LLM) code discovery under fitness uncertainty, our framework tightly couples generative foundation models with a controlled, noise-injected execution sandbox. The pipeline operates as a closed-loop evolutionary system designed to transition Python source-code structures from deterministic assumptions to noise-resilient operational behaviors. The following sections delineate our environmental wrapper implementation, the closed-loop evolutionary orchestration strategy, the structural code sanitization and tracking layers, and the statistical evaluation metrics designed to measure cross-environment generalizability.

%-------------------------------------------------------------------------------
\section{Architectural Overview}\label{sec:method_architecture}

The closed-loop discovery framework deployed in this research is structured around three primary functional layers:
\begin{enumerate}
    \item \textbf{The Generative Engine (LLM Context Window):} Formulates natural language mutation instructions and synthesizes complete, executable Python optimization classes.
    \item \textbf{The Execution and Security Sandbox:} Isolates candidate code evaluation, enforces memory and runtime limits via Abstract Syntax Tree (AST) validation, and wraps objective functions within a landscape-normalized stochastic noise layer.
    \item \textbf{The Evaluator and Diagnostic Logger:} Computes quantitative convergence metrics—specifically the Area Over the Convergence Curve (AOCC)—and extracts raw Python exception tracebacks to drive reflective context feedback.
\end{enumerate}

\section{The Stochastic Sandbox and Optimality-Gap Heteroscedastic Noise}\label{sec:method_sandbox}

To systematically evaluate whether Large Language Models can design optimization heuristics capable of surviving real-world sensory uncertainty, candidate code must be subjected to controlled, non-deterministic operational conditions \cite{Jin2005}. This research utilizes the continuous Black-Box Optimization Benchmark (BBOB) suite as its foundational testbed \cite{Hansen2010}. However, because standard benchmark instances are strictly deterministic, evaluating noise resilience required formulating an environmental noise injection wrapper over objective evaluations.

In continuous stochastic optimization literature, sensory uncertainty is predominantly simulated using either static additive white Gaussian noise \cite{Jin2005},
\begin{equation}\label{eq:static_noise_lit}
    f_{\text{noisy}}(x) = f_{\text{clean}}(x) + \mathcal{N}(0, \sigma^2)
\end{equation}
or naive point-wise multiplicative noise \cite{Jin2005},
\begin{equation}\label{eq:naive_multiplicative_lit}
    f_{\text{noisy}}(x) = f_{\text{clean}}(x) \cdot \left(1 + \mathcal{N}(0, \text{CV}^2)\right)
\end{equation}
where $x \in \mathbb{R}^D$ denotes a $D$-dimensional coordinate vector in the search space, $f_{\text{clean}}(x) \in \mathbb{R}$ represents the true deterministic objective evaluation, $\sigma^2 \in \mathbb{R}^+$ is a fixed scalar variance, $\text{CV} \in \mathbb{R}^+$ is the dimensionless Coefficient of Variation ($\text{CV} = \sigma / \mu$), and $f_{\text{noisy}}(x) \in \mathbb{R}$ is the corrupted observation returned to the search heuristic.

When applied across a heterogeneous suite of continuous functions, both standard models exhibit fundamental theoretical breakdowns \cite{Hansen2010}. Static unscaled noise (Equation~\ref{eq:static_noise_lit}) applies a fixed variance $\sigma^2$ regardless of objective magnitude. On flat landscapes where objective values near the optimum approach $10^{-5}$, static noise creates an overwhelmingly low Signal-to-Noise Ratio (SNR), swamping the true gradient signal. Conversely, on steep landscapes where objective values scale to $10^6$, an additive noise magnitude represents a negligible fraction of the objective range, allowing algorithms to exploit clean gradients without acquiring genuine noise tolerance \cite{Hansen2010}.

On the other hand, naive multiplicative noise (Equation~\ref{eq:naive_multiplicative_lit}) treats noise as proportional to the \textit{coordinate system artifact} of the function—the raw value $f_{\text{clean}}(x)$. Because $f_{\text{clean}}(x)$ includes the arbitrary constant shift of the global optimum $f(x^*)$, it contains no genuine information regarding spatial distance to the minimum. If a landscape is redefined as $g(x) = f(x) + 10,000$, naive multiplicative noise explodes by orders of magnitude with no scientific justification, obliterating the underlying basin topology.

To explicitly demonstrate this structural collapse, consider BBOB Function $f_{21}$ (Gallagher's Gaussian 101 Peaks). The true optimum is shifted to $f(x^*) \approx 40.78$, and the function's dynamic range spans roughly $50$ units (from $40$ to $90$). Under naive multiplicative noise with a coefficient of $\text{CV} = 0.05$, a candidate evaluation sitting deep within the global optimum basin at $f_{\text{clean}}(x) = 41.0$ receives a standard deviation of:
\begin{equation}\label{eq:f21_naive_std}
    \sigma = 0.05 \cdot 41.0 = 2.05
\end{equation}
A perturbation of $\pm 2.05$ represents $4\%$ of the entire dynamic range of the function. For a highly multimodal landscape where height differences between local Gaussian peaks are often just $2$ to $5$ units, this noise level completely obliterates the basin topology. If an LLM-generated algorithm evaluates two candidate solutions, $x_a$ ($f = 41.5$) and $x_b$ ($f = 42.0$), the naive formula generates extreme overlapping distributions: $f_{\text{noisy}}(x_a) \sim \mathcal{N}(41.5, 2.075^2)$ and $f_{\text{noisy}}(x_b) \sim \mathcal{N}(42.0, 2.1^2)$. The noise frequently inverts the objective ranking, providing the search heuristic with zero useful gradient signal.

Furthermore, while standard point-wise proportional noise maintains constant SNR across macro-scales, pure multiplicative noise introduces a zero-noise sanctuary near convergence. As candidate search trajectories approach $f(x^*) = 0$, local noise variance mathematically vanishes:
\begin{equation}\label{eq:vanishing_variance}
    \lim_{f(x) \to f(x^*)} \operatorname{Var}\left(f_{\text{noisy}}(x)\right) = 0
\end{equation}
where $\operatorname{Var}(\cdot)$ denotes the mathematical variance operator. This vanishing variance allows optimizers to exploit uncorrupted signals precisely at the point of convergence, defeating the purpose of a stochastic benchmark.

To resolve these limitations, this thesis formulates the \textbf{Optimality-Gap Heteroscedastic Noise Model with a Non-Zero Baseline Noise Floor}. We propose replacing raw-value multiplicative noise with a gap-anchored formulation. For any evaluation coordinate $x_k \in \mathbb{R}^D$ generated at step $k$, the point-wise standard deviation $\sigma_{\text{dynamic}}(x_k)$ scales strictly with absolute objective elevation relative to the known global minimum $f(x^*)$, while enforcing a positive noise floor $\sigma_{\text{floor}} > 0$:
\begin{equation}\label{eq:proportional_dynamic_std}
    \sigma_{\text{dynamic}}(x_k) = \text{CV} \cdot \left| f_{\text{clean}}(x_k) - f(x^*) \right| + \sigma_{\text{floor}}
\end{equation}
where $\text{CV} \ge 0$ parameterizes the relative noise intensity, $\left| f_{\text{clean}}(x_k) - f(x^*) \right|$ represents the true objective distance to the global optimum, and $\sigma_{\text{floor}} = 10^{-8}$ prevents Equation~\ref{eq:vanishing_variance} from establishing an artificial zero-noise sanctuary.

Prior to initializing any candidate optimization loop, the wrapper can also estimate a function-specific baseline landscape scale parameter $S$. Mathematically, $S$ represents a Monte Carlo expectation of the absolute objective deviation from the known global minimum $f(x^*)$ across the bounded search domain $\mathcal{S} = \prod_{d=1}^D [\text{lb}_d, \text{ub}_d]$:
\begin{equation}\label{eq:landscape_scale}
    S = \mathbb{E}_{x \sim \mathcal{U}(\mathcal{S})} \left[ \left| f(x) - f(x^*) \right| \right] \approx \frac{1}{N} \sum_{i=1}^{N} \left| f(x_i) - f(x^*) \right|
\end{equation}
To ensure deterministic consistency of $S$ across concurrent thread pools and independent experimental runs, this Monte Carlo sampling phase is locked with a fixed random initialization seed (\texttt{np.random.seed(42)}) using $N = 20$ samples.

The corrupted evaluation observation returned to the candidate search logic at step $k$ is formulated as:
\begin{equation}\label{eq:proportional_gaussian_noise}
    f_{\text{noisy}}(x_k) = f_{\text{clean}}(x_k) + z_k, \quad z_k \sim \mathcal{N}\left(0, \sigma_{\text{dynamic}}^2(x_k)\right)
\end{equation}
where $z_k \in \mathbb{R}$ is a zero-mean Gaussian random perturbation variable sampled independently at evaluation step $k$.

The continuous probability density function $p(z_k)$ governing the additive perturbation $z_k$ at evaluation step $k$ is formally expressed as:
\begin{equation}\label{eq:gaussian_pdf_dynamic}
    p(z_k) = \frac{1}{\sqrt{2\pi \sigma_{\text{dynamic}}^2(x_k)}} \exp\left( -\frac{z_k^2}{2\sigma_{\text{dynamic}}^2(x_k)} \right)
\end{equation}

Anchoring the variance dynamically to the optimality gap via Equation~\ref{eq:proportional_dynamic_std} establishes three mathematically vital properties for Automated Algorithm Design:
\begin{enumerate}
    \item \textbf{Oracle Preservation:} As search trajectories approach the global minimum ($f_{\text{clean}}(x) \to f(x^*)$), the variance smoothly transitions to $\sigma_{\text{floor}} = 10^{-8}$. The true optimum remains uniquely identifiable and statistically distinguishable at all noise levels, ensuring optimizers that successfully converge are rewarded with quiet, accurate readings.
    \item \textbf{Scale-Invariance:} The Signal-to-Noise Ratio (SNR) at any point is bounded by $1/\text{CV}$ regardless of whether the problem is $f_8$ (with a dynamic range of $\sim 10^3$) or $f_{21}$ (with a dynamic range of $\sim 50$). This standardizes environmental pressure across all benchmark topological classes without requiring per-function calibration.
    \item \textbf{Structured Difficulty:} Exploration regions far from the optimum carry high uncertainty, while exploitation regions near the optimum carry low uncertainty. This reflects highly realistic physical noise models where measurement error scales with a system's deviation from equilibrium.
\end{enumerate}

Re-evaluating the $f_{21}$ case study under this gap-anchored model ($\text{CV} = 0.05$), the two points $x_a$ ($f = 41.5$) and $x_b$ ($f = 42.0$) yield vastly superior signal integrity:
\begin{equation}\label{eq:f21_gap_std_a}
    \sigma_{\text{dynamic}}(x_a) = 0.05 \cdot |41.5 - 40.78| + 10^{-8} \approx 0.036
\end{equation}
\begin{equation}\label{eq:f21_gap_std_b}
    \sigma_{\text{dynamic}}(x_b) = 0.05 \cdot |42.0 - 40.78| + 10^{-8} \approx 0.061
\end{equation}
The resulting distributions, $f_{\text{noisy}}(x_a) \sim \mathcal{N}(41.5, 0.036^2)$ and $f_{\text{noisy}}(x_b) \sim \mathcal{N}(42.0, 0.061^2)$, strictly preserve the algorithmic ranking. The basin topology remains intact, allowing intelligently designed heuristics to filter uncertainty and navigate toward convergence.

To explicitly demonstrate the physical mechanics across contrasting topological classes, consider BBOB Function $f_8$. In the official benchmark taxonomy \cite{Hansen2010}, instance transformations apply spatial translations $x^* \in \mathbb{R}^D$ and orthonormal rotation matrices $R \in \mathbb{R}^{D \times D}$ to prevent algorithm over-specialization to coordinate axes. The mathematical formulation of $f_8$ is defined by:
\begin{equation}\label{eq:bbob_f8_formula}
    f_8(x) = \sum_{i=1}^{D-1} \left[ 100 \cdot \left( y_{i+1} - y_i^2 \right)^2 + (1 - y_i)^2 \right] + f_{\text{opt}}
\end{equation}
where $y \in \mathbb{R}^D$ represents the transformed spatial coordinate vector calculated via $y = \max\left(1, \frac{\sqrt{D}}{8}\right) R (x - x^*) + \mathbf{1}$, $\mathbf{1} \in \mathbb{R}^D$ is a vector of ones, and $f_{\text{opt}} \in \mathbb{R}$ represents the shifted global minimum value.

As visualized in Figure~\ref{fig:f8_3d_landscape}, the quadratic term $100 \cdot (y_{i+1} - y_i^2)^2$ constructs a steep parabolic valley curving across the search domain, driving objective deviations $f_{\text{clean}}(x_k) - f_{\text{opt}}$ to magnitudes on the order of $10^3$ near domain boundaries.

\section{Dual-Evaluation Decoupling and Metric Logging}\label{sec:method_decoupling}

To evaluate true optimization capability without corrupting performance tracking with stochastic variance, the experimental framework separates the feedback signal provided to the candidate algorithm from the benchmark's progress measurement. Exposing candidate algorithms to corrupted observations $f_{\text{noisy}}(x_k)$ is necessary to force the discovery of noise-resilient search logic. However, using noisy values to evaluate spatial progress would distort empirical measurement, as an algorithm could receive an unusually favorable negative noise draw ($z_k \ll 0$) that falsely suggests convergence toward $f(x^*)$. To preserve scientific rigor, candidate algorithms rely exclusively on $f_{\text{noisy}}(x_k)$ to guide internal search trajectories and step-size adaptations, while evaluation metrics record the ground-truth distance to the optimum:
\begin{equation}\label{eq:clean_distance_metric}
    \Delta f(x_k) = f_{\text{clean}}(x_k) - f(x^*)
\end{equation}
where $\Delta f(x_k) \in \mathbb{R}^+$ measures the uncorrupted objective distance from coordinate $x_k$ to the global minimum $f(x^*)$.

\section{LLM-Driven Evolutionary Code Discovery}\label{sec:method_llamea}

To enable foundation models to autonomously discover optimization heuristics specialized for stochastic environments, this framework adapts the Large Language Model Evolutionary Algorithm (LLaMEA) as its core Automated Algorithm Design engine \cite{LLaMEA2024}. Under the Automated Algorithm Design paradigm, the language model acts as a highly non-linear, semantic variation operator capable of refactoring entire software architectures, altering search mechanisms, and generating novel algorithmic logic directly from reflective execution feedback.

Rather than synthesizing generic algorithms across pooled benchmark suites, our pipeline executes LLaMEA on each target BBOB objective problem individually. This problem-specific evolutionary setup enables the language model to discover bespoke search logic tailored to the unique geometric and topological properties of a given landscape. The architecture implements a single-offspring $(1+1)$ Evolution Strategy executed directly within the language model's natural language context window. In each generation cycle $g \in \{1 \dots G\}$, where $G = 20$ denotes the maximum evolutionary generation horizon, the language model acts as a code-level mutation operator, generating exactly one candidate child algorithm $\mathcal{A}_{\text{child}}$ derived from the incumbent parent algorithm $\mathcal{A}_{\text{parent}}$.

Evolutionary code modification is governed by a structured prompt context assembled at generation $g$ via:
\begin{equation}\label{eq:context_assembly}
    \mathcal{C}_g = \left\{ \mathcal{P}_{\text{system}}, \mathcal{H}_{1 \dots g-1}, \mathcal{T}_{\text{feedback}}, F_0 \right\}
\end{equation}
where $\mathcal{C}_g$ represents the complete context window prompt at generation $g$. The $\mathcal{P}_{\text{system}}$ enforces the software contract requiring candidate classes to inherit from an abstract base optimizer interface and expose a standard entrypoint taking the problem handle, budget, dimensionality, and spatial bounds. The history log $\mathcal{H}_{1 \dots g-1}$ maintains historical code variants and performance trajectories up to generation $g-1$, while $\mathcal{T}_{\text{feedback}}$ provides reflective runtime feedback. A short directive instruction $F_0$ instructs the model to ``Either refine or redesign to improve the algorithm''.

If candidate code executes successfully, $\mathcal{T}_{\text{feedback}}$ passes scalar convergence metrics; if the code throws a runtime error, such as a matrix singularity, numerical overflow, or zero-division, the raw Python traceback is injected into the context window, enabling the model to self-debug syntax and logic errors in subsequent generations. Finally, candidate scripts undergo Abstract Syntax Tree (AST) validation prior to execution, whitelisting scientific mathematical libraries, rejecting system modules, and enforcing a hard 10-second wall-clock execution timeout.

For a targeted continuous objective function $f$, the candidate algorithm $\mathcal{A}$ is allocated a high evaluation budget of $B = 100,000$ function evaluations. The scalar fitness score assigned to algorithm $\mathcal{A}$ on problem $f$ is defined as the logarithmic minimum uncorrupted distance achieved over its trajectory:
\begin{equation}\label{eq:individual_fitness}
    \text{Fitness}(\mathcal{A}) = \log_{10} \left( \min_{k \in \{1 \dots B\}} \Delta f(x_k) \right)
\end{equation}

When operating inside a non-deterministic evaluation sandbox where $f_{\text{noisy}} = f_{\text{clean}} + z$, standard greedy selection breaks down due to what we define as the ghost parent vulnerability. Under stochastic noise, a poorly designed child algorithm may evaluate a sequence of coordinates $x_k$ that happen to receive exceptionally positive noise draws ($z \gg 0$), yielding an artificially inflated fitness score. If this over-evaluated child replaces the parent, it becomes an un-killable ghost parent. Subsequent, structurally superior offspring will be repeatedly rejected because they cannot match the ghost parent's mathematically unachievable, noise-inflated fitness score, causing evolutionary progress to stall completely.

To eliminate this bottleneck, our methodology enforces a mandatory Stochastic Parent Resampling Policy. At the conclusion of every generation cycle $g$, the incumbent parent algorithm $\mathcal{A}_{\text{parent}}$ is re-evaluated across $K=3$ independent stochastic passes, dynamically updating its stored baseline fitness to the sample mean score:
\begin{equation}\label{eq:parent_resampling}
    \bar{f}_{\text{parent}} = \frac{1}{K} \sum_{k=1}^{K} \text{Fitness}^{(k)}\left(\mathcal{A}_{\text{parent}}\right)
\end{equation}
where $K = 3$ specifies the number of Monte Carlo re-evaluation passes, $\text{Fitness}^{(k)}\left(\mathcal{A}_{\text{parent}}\right) \in \mathbb{R}$ denotes the candidate's evaluated convergence score during the $k$-th independent pass, and $\bar{f}_{\text{parent}} \in \mathbb{R}$ represents the updated mean fitness assigned to the incumbent parent. This Monte Carlo resampling policy ensures that transient noise anomalies decay rapidly, guaranteeing that selection pressure favors algorithms possessing genuine structural variance-filtering logic rather than temporary stochastic luck.

\section{Prompt Scaffolding and Architectural Directives}\label{sec:method_prompts}

While defining the physical evaluation environment is critical, the primary interface navigating the vast programmatic search space in LLM-driven Automated Algorithm Design is the natural language context window itself. To systematically investigate what cognitive and structural priors an LLM requires to synthesize noise-resilient heuristics, this methodology establishes four distinct prompt scaffolding configurations acting as independent experimental variables:

\begin{enumerate}
    \item \textbf{The BASELINE Prompt:} Serving as the experimental control group, this configuration provides strictly the operational Application Programming Interface (API) contract required to interface with the sandbox. It provides no hints regarding the topological nature of the problem nor the existence of stochastic noise, testing the LLM's raw capability to deduce noise-mitigation primitives purely from survival pressure and numeric performance feedback.
    
    \item \textbf{The THINKING Prompt:} Adapting Chain-of-Thought (CoT) protocols, this directive forces the LLM to output a dedicated mathematical deliberation block before writing any Python code. By mandating a step-by-step structural analysis of the previous generation's traceback errors and fitness deltas, this configuration evaluates whether forced algorithmic deliberation compensates for a lack of explicit domain guidance.
    
    \item \textbf{The VECTORIZATION Prompt:} A structural enforcement directive that explicitly prohibits iterative loop calculations (e.g., standard \texttt{for} loops) across candidate populations. The LLM is strictly instructed to leverage vectorized matrix operations (e.g., NumPy broadcasts) to evaluate entire populations concurrently. This tests whether constraining the model to highly efficient computational structures inadvertently accelerates or hinders its capacity for mathematical creativity.
    
    \item \textbf{The GUIDED Prompt:} Operating as the domain-expert scaffold, this configuration explicitly informs the foundation model that the evaluation landscape is heavily corrupted by point-wise variance. It suggests utilizing robust stochastic paradigms such as historical momentum, dynamic sampling, exponential moving averages, and adaptive step-size damping. This measures the absolute upper bound of LLM heuristic discovery when acting as an advanced mathematical co-pilot augmented with human priors.
\end{enumerate}

\section{Two-Phase Experimental Gauntlet and Cross-Validation}\label{sec:method_gauntlet}

To ensure empirical rigor without exhausting computational budgets, our evaluation framework is divided into two distinct competitive phases.

\subsection{Phase 1: The Intra-Framework Prompt Ablation}
To determine which scaffolding configuration produces the most robust programmatic logic, the framework evaluates the four prompt strategies on a highly representative subset of the BBOB suite. The selection encompasses five target functions, one isolated from each core structural class:
\begin{itemize}
    \item \textbf{F1 (Sphere):} Separable landscapes to evaluate base convergence speed.
    \item \textbf{F8:} Low/Moderate conditioning to evaluate boundary-to-valley navigation.
    \item \textbf{F10 (Ellipsoidal):} High conditioning to evaluate ill-conditioned coordinate rotation matrices.
    \item \textbf{F15 (Rastrigin):} Multi-modal topology featuring a strong overarching global structure.
    \item \textbf{F21 (Gallagher 101 Peaks):} Highly deceptive, randomized local optima lacking global gradients.
\end{itemize}
For each of these 5 problems, LLaMEA is executed independently using the four prompt variations under the Optimality-Gap noise model ($\text{CV} = 0.1$). This establishes a champion bespoke algorithm per problem, per prompt type.

\subsection{Phase 2: Baseline Benchmarking and Dimensional Transfer}
Once Phase 1 determines the optimal champion algorithms for the five selected functions, Phase 2 subjects these noise-evolved heuristics to classical benchmarking. The champion LLM classes are cross-evaluated against traditional, topology-agnostic human baselines: standard Covariance Matrix Adaptation Evolution Strategy (CMA-ES), Differential Evolution (DE), and Particle Swarm Optimization (PSO).

The testing gauntlet evaluates every algorithm across a grid of settings:
\begin{enumerate}
    \item \textbf{Deterministic Robustness ($\text{CV} = 0$):} Verifies if algorithms evolved under noise retain structural competence when deployed back onto clean landscapes, checking for overfitting.
    \item \textbf{Stochastic Superiority ($\text{CV} > 0$):} Quantifies how rapidly human baselines collapse under uncertainty compared to the dynamically adapted LLM champions.
\end{enumerate}

Furthermore, to test true structural generalizability, champion algorithms evolved on 5-Dimensional (5D) landscapes are zero-shot scaled and deployed against unseen 10D and 20D instances of the same problem class. This proves whether the LLM synthesized scalable geometric logic rather than memorizing flat, low-dimensional coordinate spaces.

\section{Statistical Significance Protocols}\label{sec:method_stats}

To ensure statistical significance and eliminate sensitivity to initial spatial parameters, every algorithm in Phase 2 is executed across $N = 30$ independent random seed replicates. 

Performance trajectories are formally quantified using the Area Over the Convergence Curve (AOCC). Given an evaluation budget $B = 100,000$, target precision threshold $\Delta f_t \le 10^{-8}$, and initial log-distance $\Delta f_{\text{init}}$, the AOCC is calculated as:
\begin{equation}\label{eq:aocc_formal}
    \text{AOCC} = \frac{1}{B} \sum_{k=1}^{B} \left( 1 - \frac{\log_{10}(\max(\Delta f(x_k), 10^{-8}))}{\log_{10}(\Delta f_{\text{init}})} \right)
\end{equation}

Because stochastic optimization results over independent seeds frequently exhibit heavy-tailed or skewed continuous distributions, standard parametric significance metrics (e.g., T-tests or ANOVA) are mathematically insufficient. Therefore, hypothesis testing between LLM champions and human baselines is conducted utilizing the non-parametric \textbf{Mann-Whitney U Test} with a strict significance threshold of $\alpha = 0.05$. 

To move beyond binary significance and quantify the actual magnitude of algorithmic superiority, this research implements the \textbf{Vargha-Delaney $\hat{A}_{12}$} effect size metric. The $\hat{A}_{12}$ statistic strictly measures the empirical probability that a randomly selected convergence run from the LLM champion will yield a superior AOCC score than a randomly selected run from the classical baseline, establishing an irrefutable proof of autonomous design success under uncertainty.
