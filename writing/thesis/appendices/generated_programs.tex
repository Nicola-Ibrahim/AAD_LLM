\section{Particle-Swarm Champion}

This Explicit-Clean Baseline champion was selected for $f_1$ at $D=2$
(experiment 2063, iteration 2). Its archived independent benchmark records
20 returned-point successes out of 20 trials at $\Delta f\leq10^{-8}$.

\begin{lstlisting}[style=championprogram,caption={Complete generated particle-swarm champion used in the successful case study.},label={lst:generated_pso_complete}]
import numpy as np

class ParticleSwarmOptimization:
    def __init__(self):
        self.best_x = None
        self.best_y = float('inf')

    def __call__(self, problem, budget):
        lb = np.asarray(getattr(problem, 'lower_bound', -5.0), dtype=float)
        ub = np.asarray(getattr(problem, 'upper_bound', 5.0), dtype=float)
        dim = int(getattr(problem, 'dim', len(lb) if hasattr(lb, '__len__') else 2))

        # Initialize particles randomly within the bounds
        particles = np.random.uniform(lb, ub, size=(30, dim))  # Number of particles can be tuned
        velocities = np.zeros_like(particles)
        personal_best_positions = particles.copy()
        personal_best_values = np.array([problem(x) for x in particles])

        self.best_x = personal_best_positions[np.argmin(personal_best_values)]
        self.best_y = np.min(personal_best_values)

        evaluations = len(particles)

        while evaluations < budget:
            # Update velocities and positions using PSO equations
            inertia_weight = 0.72984  # Typical value for the Inertia Weight
            cognitive_coeff = 1.49618  # Cognitive Coefficient (typically between 1.5 to 2)
            social_coeff = 1.49618    # Social Coefficient (similar to cognitive coefficient)

            r1, r2 = np.random.rand(2)
            velocities = inertia_weight * velocities + \
                         cognitive_coeff * r1 * (personal_best_positions - particles) + \
                         social_coeff * r2 * (self.best_x - particles)

            particles += velocities
            particles = np.clip(particles, lb, ub)  # Ensure particles stay within bounds

            new_values = np.array([problem(x) for x in particles])
            evaluations += len(particles)

            improvement_mask = new_values < personal_best_values
            personal_best_positions[improvement_mask] = particles[improvement_mask].copy()
            personal_best_values[improvement_mask] = new_values[improvement_mask]

            self.best_x = personal_best_positions[np.argmin(personal_best_values)]
            self.best_y = np.min(personal_best_values)

            if evaluations >= budget:
                break

        return self.best_x, float(self.best_y)
\end{lstlisting}

\section{Instance-Sensitive Evolution-Strategy Champion}

This Implicit Baseline champion was selected for $f_1$ at $D=5$ and
$\sigma=0.05$ (experiment 2139, iteration 9). Its archived independent
benchmark records nine finite returns and eleven failures. The selection
rule, empty-population failure, and evaluation-counter discrepancy are
examined in Section~\ref{subsec:generated_program_cases}.

\begin{lstlisting}[style=championprogram,caption={Complete generated \texttt{ImprovedSES} champion used in the instance-dependent failure case study.},label={lst:generated_ses_complete}]
import numpy as np

class ImprovedSES:
    def __init__(self):
        self.best_y = float('inf')
        self.evaluations = 0
        self.fitness_history = []

    def __call__(self, problem, budget):
        lb = np.asarray(getattr(problem, 'lower_bound', -5.0), dtype=float)
        ub = np.asarray(getattr(problem, 'upper_bound', 5.0), dtype=float)
        dim = int(getattr(problem, 'dim', len(lb) if hasattr(lb, '__len__') else 3))

        pop_size = 10 * dim  # Empirical choice for population size
        pop = np.random.uniform(lb, ub, size=(pop_size, dim))

        best_x = None
        self.evaluations = 0

        while self.evaluations < budget:
            fitnesses = np.array([problem(x) for x in pop])
            self.evaluations += pop_size
            self.fitness_history.append(np.min(fitnesses))

            if len(self.fitness_history) > 10 and all(f < self.best_y * 1.1 for f in self.fitness_history[-10:]):
                mutation_strength = 0.1 * (ub - lb) * (1 - self.evaluations / budget) * 0.5  # Decrease strength and make it more conservative
            else:
                mutation_strength = 0.1 * (ub - lb) * (1 - self.evaluations / budget)

            idx = np.argsort(fitnesses)[:int(pop_size // 2)]
            parents = pop[idx]
            good_candidates_index = fitnesses[idx] < self.best_y * 1.1
            parents = parents[good_candidates_index]

            mutants = np.clip(parents + np.random.normal(0, mutation_strength, size=parents.shape), lb, ub)
            pop = np.vstack([parents, mutants])

            new_fitnesses = np.array([problem(x) for x in pop])
            self.evaluations += len(new_fitnesses) - len(fitnesses)  # Update evaluation count

            current_best_idx = np.argmin(new_fitnesses)
            if new_fitnesses[current_best_idx] < self.best_y:
                best_x = pop[current_best_idx].copy()
                self.best_y = new_fitnesses[current_best_idx]

        return best_x, float(self.best_y)
\end{lstlisting}
